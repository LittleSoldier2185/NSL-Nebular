ER Table Form

กล่องสร้าง/แก้ตาราง ER ใหม่ พร้อม CHECK และค่าที่อนุญาต (ENUM)

ตัวอย่างคือตาราง bookings ของไฟล์โรงแรม กล่องมี 4 แท็บ (คอลัมน์ · ดัชนี · CHECK · ข้อมูลตั้งต้น) และแถบ SQL ด้านล่างที่เปลี่ยนตาม dialect ส่วนที่ยังไม่ตัดสินคือหน้าตาของแท็บ "คอลัมน์" ซึ่งมี 3 แบบให้สลับดู กดเพิ่ม/ลบค่า ติ๊ก Null เปลี่ยนชนิด ผลสะท้อนในแถบ SQL ทันที

Dialect
แบบของแท็บคอลัมน์

ผมแนะนำแบบ C

ยังเป็นตารางที่กรอกต่อเนื่องได้เร็วเหมือนเดิม (คนที่คุ้น phpMyAdmin ไม่ต้องเรียนใหม่) ส่วนค่าที่อนุญาต หมายเหตุ ค่าเริ่มต้นแบบเลือกจากรายการ ไปอยู่ในแถบขยายใต้แถวที่ต้องการ คอลัมน์ที่มีค่าที่อนุญาตขึ้นป้าย ENUM ให้เห็นทันที แบบ A กว้างจนต้องเลื่อนแนวนอน แบบ B ต้องคลิกทีละคอลัมน์จึงช้าเวลาสร้างตารางใหม่ 20 คอลัมน์

กติกาที่เสนอ

  • ค่าที่อนุญาตใช้ได้กับคอลัมน์ varchar / text ก่อน (จำนวนเต็มไว้รอบหลัง) ค่าซ้ำ/ว่างแจ้งเตือน
  • MySQL/MariaDB สร้าง ENUM(...) ; dialect อื่นสร้าง CHECK (col IN (...)) ; ค่าเริ่มต้นต้องอยู่ในรายการ
  • CHECK ระดับตาราง: ชื่อ + นิพจน์ ; ตรวจว่าคอลัมน์ที่อ้างถึงมีอยู่จริง (เปลี่ยนชื่อคอลัมน์แล้วแจ้งให้แก้)
  • ข้อมูลตั้งต้น: ช่องของคอลัมน์ที่มีค่าที่อนุญาตเป็นรายการเลือก ค่านอกรายการขึ้นแดง
  • ไม่รวม exclusion constraint (ใช้น้อย เฉพาะ PostgreSQL)

ที่ต้องตัดสินใจ

  • แบบของแท็บคอลัมน์: A, B หรือ C
  • ข้อมูลตั้งต้นย้ายมาเป็นแท็บในกล่องนี้ (ตามภาพ) หรือคงกล่องแยกเดิมที่เปิดจากแผงขวา
  • แถบ SQL ด้านล่างกล่อง เปิดไว้เป็นค่าเริ่มต้น หรือพับไว้ให้กดดู
