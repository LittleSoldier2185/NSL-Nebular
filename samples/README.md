# ไฟล์ SQL ตัวอย่างสำหรับทดสอบ

ใช้กับเมนู **ไฟล์ > นำเข้าจาก .sql…** (หรือ Ctrl+I) เพื่อดูว่าโปรแกรมอ่านโครงสร้างแล้ววาดเป็นแผนภาพได้ถูกต้องไหม

| ไฟล์ | Dialect | ตาราง | จุดที่ใช้ทดสอบ |
|------|---------|-------|----------------|
| `shop_mysql.sql` | MySQL / MariaDB | 7 | FK 1:N, ตารางเชื่อม N:M (PK ผสม), self-reference, `ALTER TABLE … ADD CONSTRAINT`, INDEX, `COMMENT` |
| `blog_postgres.sql` | PostgreSQL | 5 | `SERIAL`/`BIGSERIAL`, `BOOLEAN`, FK ผ่าน `ALTER TABLE`, `CREATE UNIQUE INDEX`, `COMMENT ON` |
| `school_sqlite.sql` | SQLite | 4 | FK ในตัว `CREATE TABLE`, `AUTOINCREMENT`, PK ผสม 3 คอลัมน์ |

`shop_mysql.sql` และ `school_sqlite.sql` มีคำสั่ง `SET NAMES` / `PRAGMA` ตั้งใจใส่ไว้ เพื่อดูแผง "สิ่งที่ควรตรวจ" ที่แจ้งว่าข้ามคำสั่งที่ไม่ใช่โครงสร้างตาราง ส่วน `blog_postgres.sql` นำเข้าได้โดยไม่มีคำเตือน

ทดสอบต่อได้ด้วยการนำเข้าแล้วสลับ dialect เป็นตัวอื่น จากนั้น Export `.sql` เพื่อดูว่าแปลงชนิดข้อมูลถูกต้อง
หรือใช้ **เปรียบเทียบกับไฟล์เก่า (Migration)** หลังแก้แผนภาพ

`test/sample_sql_test.dart` นำเข้าไฟล์เหล่านี้ทุกครั้งที่รันเทสต์ เพื่อกันไม่ให้ตัวอย่างหรือ importer พังโดยไม่รู้ตัว

## โปรเจกต์ตัวอย่างเต็มรูปแบบ: `hotel_booking.nsln`

เว็บจองห้องพักโรงแรม (Siam Residence) — **ใช้ครบทุกชนิดเอกสาร** เปิดด้วย **ไฟล์ > เปิด** ได้เลย :

| เอกสาร | เนื้อหา |
|---|---|
| ER (MySQL) | 9 ตาราง, FK 8 เส้น, ข้อมูลตั้งต้น, ดัชนี, กลุ่มตาราง, โน้ตบนแคนวาส |
| DFD ระดับ 0 และ 1 | 5 กระบวนการ, ที่เก็บข้อมูล D1–D5 ผูกตาราง ER, สมดุลกับระดับ 0, กระบวนการ 0 แตกไประดับ 1 |
| Flowchart | ขั้นตอนการจอง (ตัดสินใจ 3 จุด, โปรแกรมย่อย, โน้ต) |
| Wireframe 7 หน้า | หน้าแรก, รายการห้อง, รายละเอียดห้อง, ชำระเงิน, การจองของฉัน, แอดมิน 2 หน้า — ใช้ชิ้นส่วนเกือบครบ 45 ชนิด, ผูกข้อมูล ER และ endpoint, มีกลุ่ม/ชิ้นที่ซ่อน/ชิ้นที่หมุน |
| Screen Flow | 10 หน้าจอ/จุด ผูกกับ Wireframe, เงื่อนไขบนเส้น, เส้นเรียก endpoint |
| API | 22 endpoint ผูกตาราง ER, ฟิลด์ผูกคอลัมน์, สิทธิ์ล็อกอิน, ตัวอย่าง response |
| ความต้องการ | 10 ข้อ ไล่ตามครบ 8 ข้อ ; **REQ-09 / REQ-10 ตั้งใจเว้นช่องไว้** ให้ทดสอบเมทริกซ์ช่องว่างและ "สร้างเอกสารจากช่องว่าง" |
| โน้ตและงานค้าง | ทั้งแบบปักหมุด ผูกวัตถุ ต้องทำ/คำถาม/บันทึก/เสร็จแล้ว |
| ชุดตั้งค่าในไฟล์ | เป้าหมายสร้างโค้ดและโฟลเดอร์ (`generated/hotel`), พอร์ตและสถานการณ์ของ Mock Server |

ไฟล์นี้สร้างด้วย `dart run tool/gen_hotel_sample.dart samples/hotel_booking.nsln` (ใช้โมเดลเดียวกับโปรแกรม — แก้สคริปต์แล้วสร้างใหม่ได้) และ `test/hotel_sample_test.dart` เปิดไฟล์นี้ในแอป ตรวจ ส่งออก สร้างโค้ดทุกครั้งที่รันเทสต์

ลองใช้ผ่าน CLI : `nebular validate samples/hotel_booking.nsln` · `nebular codegen samples/hotel_booking.nsln --targets all --out out/`
